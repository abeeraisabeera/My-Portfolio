RAG Research Assistant — grounded answers from PDFs

Retrieval-Augmented Generation over a PDF research corpus: parse and chunk papers, embed with Sentence-Transformers, index with FAISS, retrieve top passages, and generate answers via Groq — instructed to stay within retrieved context.

PDFs → Parse · chunk → Embed → FAISS → Top-K context → Groq LLM

Approach

  • PyMuPDF page parsing; ~1000-char chunks with 200 overlap
  • all-MiniLM-L6-v2 embeddings (384-d)
  • FAISS IndexFlatIP; top-5 retrieval
  • Groq inference with context-only answering instructions
  • MLflow tracking for experiment hygiene

Limitations

  • Designed for Google Colab workflows
  • Quality depends on corpus coverage and retrieval relevance
  • Requires a Groq API key (Colab secret)
