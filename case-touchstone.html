TouchStone (Kasauti) — test whether Variant B is real lift

Production-style experimentation platform: generate synthetic A/B datasets for food delivery and banking / fintech, run statistical evaluation, inspect decision-ready charts, and export a report that reads like an internal Product Analytics memo.

Problem

Teams often ship product changes without a clear statistical story. TouchStone asks: is Variant B true lift — or fool’s gold?

Approach

  • Scenario library with traffic splits and MDE-minded setups
  • Synthetic generators for food delivery and fintech
  • Shared stats engine: two-proportion z-tests, CIs, effect sizes
  • Charts + PDF/CSV export for decision memos

Architecture

Next.js + Tailwind + Recharts frontend talks to a FastAPI stats API (Vercel) that owns generation, schema normalization, and the statistics core.

What it demonstrates

Statistical foundations for product decisions: power / sample sufficiency framing, bootstrap confidence intervals, and ship-or-stop language instead of vanity metrics.
