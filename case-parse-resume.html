Parse Your Resume — ATS scoring & candidate ranking

Production-minded resume system that extracts structured candidate data from PDFs, scores applicants across role-aware dimensions, and ranks them for recruitment pipelines — with a FastAPI backend and a Vercel dashboard.

Problem

Recruiters drown in unstructured PDFs. Manual shortlisting is slow, inconsistent, and weak on scanned or creative-portfolio resumes. Teams need structured fields, comparable scores, and a ranking view — not another black-box “AI score.”

Motivation

Build a split architecture that can actually run: reliable PDF ingestion with OCR fallback, hybrid rule + LLM parsing, role-aware weighting, and a dashboard that shortlists and exports candidates.

Approach

  • Multi-engine extraction: PyMuPDF → pdfplumber → OCR (Tesseract) fallback
  • Hybrid parsing: regex / rules + Groq LLM semantic enrichment
  • Role-aware scoring (e.g. design, marketing, general) with ranking scores
  • Behance portfolio enrichment for creative candidates
  • Retry logic with exponential backoff for rate-limited LLM calls
  • REST API: parse, batch parse, candidates, shortlist, delete

Deployment (as documented)

  • Frontend: Vercel candidate dashboard
  • Backend: FastAPI on Hugging Face Spaces (Docker)
  • Database: Neon PostgreSQL
  • LLM: Groq API
  • Cold starts possible after HF inactivity; OCR needs Tesseract in the runtime

Architecture

PDF upload → Extract · OCR → Rules + Groq → Scoring engine → Neon store → Ranked dashboard

Output shape

Structured candidate JSON (name, email, skills, experience, seniority, ranking score) for pipeline use — plus shortlist controls in the UI.

Technology

Python, FastAPI, PyMuPDF, pdfplumber, Tesseract OCR, BeautifulSoup, Groq, Neon PostgreSQL, Vercel frontend. Repo documents 170+ test cases.
