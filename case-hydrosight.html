HydroSight — climate-aware AI workload insight

Observe-first dashboard that connects FortyGuard thermal conditions to modeled water and carbon estimates for AI workloads — then ranks cooler / less water-intensive site × hour windows with explicit provenance labels.

Problem

AI training and inference create thermal and water pressure on infrastructure. Operators need climate-aware tradeoffs for where and when to run workloads — without false claims of measured datacenter WUE.

Motivation

Sustainability decisions fail when models hide assumptions. HydroSight prioritizes provenance before math: LIVE FortyGuard tiles, last filled TCM backfill, or ASSUMED climatology — always labeled.

Approach

  • Map live (or mock) site climates with Leaflet / OSM
  • Optional Modeled path for water/carbon estimates
  • Rank site × hour windows under a carbon constraint
  • Fail-closed live mode; empty TCM hours backfill honestly

Limitations (stated in repo)

  • Does not measure datacenter WUE
  • Does not schedule jobs or guarantee savings
  • Research prototype — not a production scheduler

Architecture

FortyGuard TCM / env → FastAPI climate API → Next.js observe map → Modeled water/carbon → Site × hour ranking

Technology

Next.js, FastAPI (Python), FortyGuard, Leaflet / OpenStreetMap. Version documented in repo as 0.8.0 research prototype.

Next iteration

Deeper validation of modeled equations against additional climate sources, and clearer operator workflows for comparing LIVE vs ASSUMED paths.
